# 🎬 MAWAMOVIE - Movie Ticket Booking Website (Frontend Project)

Welcome to **MAWA_MOVIE**, a simple and stylish movie ticket booking website made with **HTML, CSS, and JavaScript**.  
It provides a clean and interactive interface for users to browse movies and book seats.

---

## ✨ Features

- 🎞️ Browse movie listings with posters and showtimes
- 🪑 Interactive seat selection page
- 📄 Booking confirmation screen
- 💻 Responsive layout for mobile and desktop
- 🎨 Clean and modern design using only frontend technologies

---

## 💻 Built With

- **HTML** – Structure
- **CSS** – Styling (custom or with Bootstrap)
- **JavaScript** – Interaction (seat selection, booking logic)
